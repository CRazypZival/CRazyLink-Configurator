QUICK START

三步开始

  1. 通过 FTDI 给 TX/RX 烧录固件，给 RX 接上 SWD 和目标 UART。
  2. 使用 Chrome 或 Edge 打开本页面，点击连接设备。
  3. 选择固件、确认参数，开始烧录或打开串口。

TX 的原生 USB 用于功能接口；UART0 只用于开发烧录和日志。
